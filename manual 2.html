Manual Operacional - Sistema Saúde Maternal

1. Visão Geral

O sistema Saúde Maternal é uma plataforma web para gestão completa do pré-natal, incluindo cadastro de gestantes, acompanhamento clínico, exames e desfechos.

Tecnologias

  • Next.js 14
  • React + TypeScript
  • Supabase (PostgreSQL)
  • Tailwind CSS

2. Autenticação

Login

  • CPF (validado)
  • Senha
⚠️ Usuários bloqueados não conseguem acessar o sistema.

Níveis

  • Administrador: acesso total
  • Usuário: restrito à unidade

Diagrama de Relacionamentos

Entidades e Relacionamentos

Legenda: PK = Chave Primária | FK = Chave Estrangeira | 1:N = Um para Muitos | N:1 = Muitos para Um | 1:1 = Um para Um

1. UNIDADES SAÚDE (1:N) → OPERADORES

Uma unidade de saúde pode ter vários operadores cadastrados. Um operador pertence a uma única unidade.

2. PACIENTES (1:N) → GESTAÇÕES

Uma paciente pode ter várias gestações ao longo do tempo. Cada gestação está vinculada a uma única paciente.

3. GESTAÇÕES (1:N) → ATENDIMENTOS

Uma gestação pode ter vários atendimentos/consultas. Cada atendimento pertence a uma única gestação.

4. GESTAÇÕES (1:N) → DESFECHOS

Uma gestação pode ter apenas um desfecho (encerramento). Cada desfecho pertence a uma única gestação.

5. DESFECHOS (1:N) → RECÉM-NASCIDOS

Um desfecho do tipo "PARTO" pode ter vários RNs (gemelar). Cada RN pertence a um único desfecho.

6. ROTINAS (1:N) → REGISTRO ROTINAS

Uma rotina pode ser realizada várias vezes (em diferentes gestações). Cada registro pertence a uma única rotina.

7. CATEGORIAS PROFISSIONAIS (1:N) → PROFISSIONAIS

Uma categoria profissional (CBO) pode ter vários profissionais. Cada profissional possui uma única categoria.

8. UNIDADES SAÚDE (1:N) → PROFISSIONAIS

Uma unidade de saúde pode ter vários profissionais atuação. Um profissional pode atuar em uma unidade.

9. UNIDADES SAÚDE (1:N) → GESTAÇÕES

Uma unidade de saúde pode registrar várias gestações. Cada gestação é vinculada a uma unidade.

10. UNIDADES SAÚDE (1:N) → ROTINAS (opcional)

Uma unidade pode ter rotinas específicas configuradas (opcional).

11. UNIDADES SAÚDE (1:N) → REGISTRO ROTINAS

Uma unidade pode ter vários registros de rotinas. Cada registro pertence a uma unidade.
